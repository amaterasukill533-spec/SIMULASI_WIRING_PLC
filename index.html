📖 Panduan & Tata Cara Simulator PLC

👋 Mulai di Sini: Cara Menggunakan Simulator

  1. Pilih rangkaian. Klik titik tiga (⋮), lalu pada Preset Logika PLC pilih Forward-Reverse, DOL, atau Jogging. Komponen akan menyesuaikan preset.
  2. Baca panduan wiring preset. Di menu yang sama, tekan tombol panduan yang sesuai: Wiring Forward-Reverse, Wiring DOL Start-Stop, atau Wiring Inching / Jogging.
  3. Buat sambungan. Klik terminal bulat pada komponen sumber, lalu klik terminal tujuan. Ulangi untuk setiap pasangan koneksi sesuai panduan.
  4. Rapikan jalur. Tekan ✨ Rapikan untuk merutekan kabel dengan belokan siku. Gunakan 📍 Titik untuk menambah/mengatur titik belok secara manual.
  5. Uji rangkaian. Nyalakan sumber/MCB bila diperlukan, operasikan tombol kontrol, lalu amati LED input/output PLC, kontaktor, lampu, dan motor.
  6. Perbaiki kesalahan. Tekan 🔍 Periksa / Diagnostik Wiring dari menu titik tiga. Gunakan ✂ Hapus untuk menghapus kabel yang dipilih atau Undo untuk membatalkan sambungan terakhir.

🔌 Dasar Wiring & Terminal

  • Pasang kabel: klik terminal sumber satu kali, kemudian terminal tujuan satu kali. Sambungan dibuat antara dua terminal tersebut.
  • Warna kabel: pilih warna dari titik warna di toolbar sebelum membuat kabel. Warna membantu membedakan jalur, tetapi bukan pengganti pemeriksaan koneksi.
  • PSU dan input PLC: ikuti polaritas PSU serta terminal COM pada rangkaian. COM ke PSU −V umumnya membuat input aktif ketika +V diberikan ke input; COM ke PSU +V membuat input aktif ketika −V diberikan. Periksa kesesuaian skema dan jenis input sebelum menguji.
  • Catatan keselamatan: ini simulator edukasi. Untuk instalasi nyata, putuskan sumber daya sebelum mengubah wiring dan verifikasi skema dengan instruktur/teknisi yang kompeten.

🧰 Kontrol Toolbar

  • ✨ Rapikan: merapikan seluruh jalur kabel secara otomatis.
  • 📍 Titik: mengatur belokan jalur kabel secara manual.
  • ✂ Hapus: aktifkan mode hapus lalu klik kabel yang ingin dihapus.
  • Undo / Zoom / Fit: membatalkan sambungan terakhir, memperbesar/memperkecil tampilan, atau menyesuaikan seluruh area kerja.
  • Komponen manual: dari menu titik tiga, tombol komponen dapat menampilkan/menyembunyikan komponen opsional. Menyembunyikan komponen juga menghapus kabel yang terhubung kepadanya.
